# Init - 初始化專案 AI 上下文

以「根級簡明 + 模組級詳盡」策略生成專案 AI 上下文文件。

## 使用方法

```bash
/init <專案摘要或名稱>
```

## 上下文

- 專案摘要：$ARGUMENTS
- 生成/更新根級與模組級 `CLAUDE.md`
- 自動生成 Mermaid 結構圖和導航麵包屑

## 你的角色

你是**協調者**，負責呼叫子智慧體完成專案掃描與文件生成。

---

## 執行工作流

**⚠️ 必須按以下步驟執行，使用 Task 工具呼叫子智慧體**

### 🕐 步驟 1：獲取當前時間戳

**必須首先呼叫 `get-current-datetime` 子智慧體**：

```
Task({
  subagent_type: "get-current-datetime",
  prompt: "獲取當前日期時間，用於文件時間戳",
  description: "獲取當前時間"
})
```

等待返回時間戳後，儲存為 `$TIMESTAMP` 供後續使用。

### 🏗️ 步驟 2：呼叫初始化架構師

**使用 `init-architect` 子智慧體執行完整掃描**：

```
Task({
  subagent_type: "init-architect",
  prompt: "掃描專案並生成 CLAUDE.md 文件。\n\n專案摘要：$ARGUMENTS\n當前時間戳：$TIMESTAMP\n工作目錄：{{WORKDIR}}\n\n請執行：\n1. 階段 A：全倉清點（檔案統計、模組識別）\n2. 階段 B：模組優先掃描（入口、介面、依賴、測試）\n3. 階段 C：深度補撈（按需）\n4. 階段 D：生成文件（根級 + 模組級 CLAUDE.md）\n\n輸出覆蓋率報告與推薦下一步。",
  description: "初始化專案文件"
})
```

### 📊 步驟 3：彙總結果

子智慧體完成後，向使用者展示：

```markdown
## 初始化結果摘要

### 根級文件
- 狀態：[建立/更新]
- 主要欄目：<列表>

### 模組識別
- 識別模組數：X
- 模組列表：
  1. <模組路徑>
  2. ...

### 覆蓋率
- 已掃描檔案：X / Y
- 覆蓋模組：X%
- 跳過原因：<如有>

### 生成內容
- ✅ Mermaid 結構圖
- ✅ N 個模組導航麵包屑

### 推薦下一步
- [ ] 補掃：<路徑>
```

## 安全邊界

1. **只讀/寫文件** – 不改原始碼
2. **忽略生成物** – 跳過 `node_modules`、`dist`、二進位制檔案
3. **增量更新** – 重複執行時做斷點續掃

## 關鍵規則

1. **必須使用 Task 工具**呼叫子智慧體，不要自己執行掃描邏輯
2. 先呼叫 `get-current-datetime` 獲取時間戳
3. 再呼叫 `init-architect` 執行完整掃描
4. 結果在主對話列印摘要，全文由子智慧體寫入倉庫
